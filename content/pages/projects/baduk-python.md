## BadukPython: Play Baduk (Go) on Desktop

BadukPython is a desktop application for playing Baduk (Go), designed for simplicity and ease of use. Built with Python, it is open source and available for Windows, macOS, and Linux.

### Key Features

- **9x9 Board**: Classic Baduk board with star points
- **Captured Stones Counter**: Automatically tracks captured stones
- **Pass & Main Menu Buttons**: Easy game control
- **Simple, Clean UI**: Focused on gameplay
- **Open Source**: [View on GitHub](https://github.com/ManaInfectedRP/BadukPython)
- **Download**: [Releases on GitHub](https://github.com/ManaInfectedRP/BadukPython/releases)
- **Play Online**: [Itch.io Page](https://sebbepwnyou.itch.io/baduk-in-python)

### Technical Stack

- Python (Tkinter for UI)
- Cross-platform desktop support
